## [Unreleased]

### Added

- Initial public scaffold: API service, Node SDK, NFC parser, dashboard skeleton.
- ICAO 9303 LDS parsing for DG1, DG2, DG13.
- Passive Authentication against pluggable CSCA trust anchors.
- Stripe-style error envelope, idempotency keys, prefixed IDs.
- Webhook delivery with HMAC signing, exponential backoff with jitter, replay protection.
- Multi-tenant API key issuance with Argon2id hashing + HMAC lookup index.
- Dev stack via Docker Compose: Postgres, Redis, MinIO, Jaeger.
- CI on GitHub Actions: lint, typecheck, unit tests, Docker build, CodeQL, dependency audit.
